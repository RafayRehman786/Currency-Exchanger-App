💱 Currency Converter

A modern, responsive, and accurate Currency Converter web application that allows users to convert between global currencies in real time. Built with a clean and intuitive interface, it showcases API integration, responsive design, and seamless user experience principles.

🚀 Key Features

🌍 Real-Time Exchange Rates: Retrieves up-to-date currency data from a reliable exchange rate API.

💡 Dynamic Conversion: Instantly updates results as users change input amounts or select different currencies.

🧭 User-Friendly Interface: Features a clean, responsive layout for smooth usage across desktop and mobile devices.

⚡ Lightweight & Efficient: Optimized for performance with minimal dependencies and fast loading times.

🔄 Multi-Currency Support: Enables conversion between a wide range of international currencies.

🛠️ Tech Stack

Frontend: HTML5, CSS3, JavaScript

API Integration: ExchangeRate API

Version Control: Git & GitHub

This project demonstrates strong frontend development and API integration skills while emphasizing responsive design, usability, and performance. It’s a practical example of how real-time data can be combined with modern web technologies to create a reliable and visually appealing financial tool.
